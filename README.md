# LineMeasurePro — קבצים ורליסים

הריפו הציבורי של **LineMeasurePro**, תוסף המדידה והכימות לאוטוקאד.

כאן יושבים שני דברים בלבד: **חבילות ההתקנה** של כל גרסה, ו**עץ הקבצים** שהאפליקציה
מציגה. קוד המקור אינו כאן ואינו יוצא לכאן לעולם — הוא בריפו פרטי נפרד.

## הורדת התוסף

הגרסה האחרונה נמצאת תמיד תחת [Releases](../../releases/latest). מורידים את קובץ ה-zip,
מחלצים, ומריצים `Install.bat`.

החבילה כוללת שני bundles:

| Bundle | גרסאות אוטוקאד |
|---|---|
| `2025-2026_LineMeasurePro.bundle` | AutoCAD / Civil 3D 2025, 2026 |
| `2027_LineMeasurePro2027.bundle` | AutoCAD / Civil 3D 2027 |

`Install.bat` מזהה לבד אילו גרסאות מותקנות במחשב ומתקין רק את מה שמתאים.

## עץ הקבצים

התיקייה [`files/`](files/) היא ספריית התוכן שהאפליקציה מציגה — תיקיות בתוך תיקיות,
בדיוק כפי שהן מסודרות כאן. מה שרואים כאן ב-GitHub הוא מה שרואים באפליקציה.

להוספת תוכן: גוררים קבצים לתיקייה הרצויה דרך ממשק GitHub, או דוחפים ב-git.
אין צורך להריץ שום דבר — ה-workflow `Rebuild file index` בונה מחדש את `index.json`
אוטומטית בכל שינוי תחת `files/`.

## הקבצים בשורש

| קובץ | מה זה | נוצר על ידי |
|---|---|---|
| `index.json` | עץ הקבצים המלא — שם, נתיב, סוג, גודל ו-URL לכל צומת | `tools/build_index.py` דרך workflow |
| `latest-linemeasurepro.json` | הגרסה האחרונה של תוסף האוטוקאד | workflow הרליס בריפו הפרטי |
| `latest-civicflow.json` | הגרסה האחרונה של CivicFlow | מפורסם בנפרד |
| `latest.json` | עותק של `latest-linemeasurepro.json` | תאימות לאחור בלבד — ראה למטה |

## קובץ עדכונים לכל תוסף בנפרד

כל תוסף קורא **רק את הקובץ שלו**. זה מכוון: שחרור גרסה של תוסף האוטוקאד לא אמור
להזיז את מספר הגרסה של CivicFlow, ולא אמור להודיע למשתמשי CivicFlow שיש להם עדכון.
כתיבה פגומה לאחד לא יכולה לשבור את בדיקת העדכונים של השני.

`latest.json` נשאר ככפילות של `latest-linemeasurepro.json` כי גרסה 1.2.0 שוחררה
כשזה היה השם היחיד; אם היינו מפסיקים לכתוב אותו, ההתקנות של 1.2.0 היו מקבלות 404
בכל בדיקה ולעולם לא היו לומדות שיש גרסה חדשה. אפשר למחוק אותו כשלא נשארה התקנה
של 1.2.0.

מבנה הקובץ:

```json
{
  "version": "1.3.0",
  "tag": "v1.3.0",
  "notes_url": "https://github.com/maozwe/LineMeasurePro-releases/releases/tag/v1.3.0",
  "artifacts": {
    "installer": { "url": "...", "sha256": "...", "size": 6140722 }
  }
}
```

ה-`sha256` אינו קישוט: התוסף מסרב להתקין חבילה שה-hash שלה לא תואם, מה שחוסם הורדה
קטועה, דף התחברות של רשת אורחים שהוחזר במקום הקובץ, וארכיון שהוחלף.

כל הקבצים נקראים מ-`raw.githubusercontent.com` ולא דרך ה-API של GitHub. ה-API
מוגבל ל-60 בקשות בשעה לכתובת IP לא מאומתת — משרד מאחורי כתובת אחת גומר את המכסה
מהר, ואי אפשר להבדיל בין זה לבין קבצים שנעלמו. בקשה אחת, מטמון CDN, בלי מגבלה.

קובץ שלא קיים מחזיר 404, וזה המצב הרגיל של תוסף שטרם שוחרר — לא שגיאה.

## איך מגיע העדכון למשתמש

**תוסף האוטוקאד** בודק בכל הפעלה של אוטוקאד. אם יש גרסה חדשה הוא מוריד ומאמת אותה
ברקע, ומשאיר תהליך שממתין לסגירת האוטוקאד כדי להחליף את ה-bundle. הסיבה שההחלפה
לא מיידית: אוטוקאד נועל את ה-DLL שטען ומריץ אותו מהזיכרון, כך שאין דרך להחליף אותו
תוך כדי ריצה. הגרסה החדשה פעילה בהפעלה הבאה. יש גם כפתור עדכון ידני בפאנל.

**CivicFlow** בודק כשנפתחת תצוגת הספרייה, ומוריד ומאמת לפי בקשה.
