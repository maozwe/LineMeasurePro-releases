# התקנה והפעלה

## התקנה

1. פתח את [דף ההורדות](../../../releases/latest).
2. הורד את הקובץ `LineMeasurePro-Setup-<גרסה>.exe`.
3. **סגור את אוטוקאד לגמרי**, והרץ את הקובץ שהורדת.

ההתקנה מזהה לבד אילו גרסאות אוטוקאד מותקנות במחשב ומסמנת רק את המתאימות להן.
אין צורך בהרשאות מנהל — ההתקנה היא למשתמש הנוכחי בלבד.

לאחר ההתקנה — פתח את אוטוקאד. הרצועה **LineMeasurePro** תיטען אוטומטית.

### Windows יציג אזהרה כחולה

בהרצת קובץ ההתקנה Windows יציג מסך בשם **"Windows protected your PC"**.
לחץ על **More info** ואז על **Run anyway**.

זה קורה לכל תוכנה שלא נרכשה עבורה תעודת חתימה דיגיטלית בתשלום, ואינו מעיד
על בעיה בקובץ. כדי לוודא שהקובץ לא שונה בדרך, אפשר להשוות את ה-SHA256 שלו
לזה שמופיע בדף ההורדות:

```powershell
Get-FileHash "LineMeasurePro-Setup-<גרסה>.exe"
```

### התקנה בלי קובץ ההתקנה

מי שהמחשב שלו חוסם הרצת קבצי `exe` שהורדו מהאינטרנט יכול להוריד במקום זאת
את קובץ ה-`zip` מאותו דף, לחלץ אותו, ולהריץ `Install.bat`. התוצאה זהה.

## הפעלה

הרצועה נטענת אוטומטית. אפשר גם לפתוח את הפאנל בפקודה:

```
LMPDOCK
```

בהפעלה הראשונה מתחילים אוטומטית 30 יום ניסיון מלא. אין צורך בקוד כדי להתחיל.

## פקודות עיקריות

| פקודה | מה היא עושה |
|---|---|
| `LMPDOCK` | פותח את הפאנל העגין |
| `LMPLINES` | מדידת אורכים וסימונם |
| `LMPAREAS` | מדידת שטחים וסימונם |
| `LMPBLOCKS` | ספירת בלוקים |
| `LMPSUMMARY` | חלון הסיכום |
| `LMPTOEXCEL` | ייצוא לאקסל |
| `LMPNUMBER` | מספור |
| `LMPACTIVATE` | הפעלת רישיון |

אוטוקאד 2021 ומטה — אינה נתמכת.

## עדכון גרסה

התוסף בודק בכל פתיחה של אוטוקאד אם יצאה גרסה חדשה, ומודיע. אפשר לאשר את
העדכון מתוך התוסף — הוא יורד, נבדק, ומוחלף בסגירת אוטוקאד הבאה.

אין צורך להוריד את קובץ ההתקנה שוב כדי לעדכן.

## הסרה

**הגדרות Windows → אפליקציות → LineMeasurePro → הסר.**

מי שהתקין מקובץ ה-zip יריץ במקום זאת את `Uninstall.bat` שבאותה חבילה.

הרישיון והמפתח **אינם נמחקים** בהסרה, כך שהתקנה חוזרת מוצאת אותם.
