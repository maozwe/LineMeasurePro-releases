# התקנה והפעלה

## התקנה

1. הורד את קובץ ה-zip מהגרסה האחרונה תחת [Releases](../../../releases/latest).
2. חלץ את התוכן לתיקייה כלשהי.
3. הרץ `Install.bat`.

ההתקנה מזהה לבד אילו גרסאות אוטוקאד מותקנות ומעתיקה רק את ה-bundle המתאים לכל אחת.
אין צורך להריץ כמנהל, וההתקנה היא למשתמש הנוכחי בלבד.

לאחר ההתקנה — יש לסגור ולפתוח מחדש את האוטוקאד.

## הפעלה

הרצועה **LineMeasurePro** נטענת אוטומטית. אפשר גם לפתוח את הפאנל בפקודה:

```
LMPDOCK
```

## פקודות עיקריות

| פקודה | מה היא עושה |
|---|---|
| `LMPDOCK` | פותח את הפאנל העגין |
| `LMPLINES` | מדידת אורכים וסימונם |
| `LMPAREAS` | מדידת שטחים וסימונם |
| `LMPBLOCKS` | ספירת בלוקים |
| `LMPSUMMARY` | חלון הסיכום |
| `LMPTOEXCEL` | ייצוא לאקסל |
| `LMPNUMBER` | מספור |
| `LMPACTIVATE` | הפעלת רישיון |

## הסרה

`Uninstall.bat` שבאותה חבילה מסיר את כל ה-bundles שהותקנו.
