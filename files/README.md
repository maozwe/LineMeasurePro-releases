# עץ הקבצים

מה שמסודר כאן הוא מה שהמשתמש רואה באפליקציה. תיקייה כאן = תיקייה שם, קובץ כאן =
קובץ שם, באותו סדר: תיקיות קודם, אחר כך קבצים, כל קבוצה לפי א־ב.

התיקיות שקיימות עכשיו הן **התחלה בלבד** — שנה שמות, מחק, והוסף לפי מה שבאמת צריך
להגיע למשתמשים.

## איך מוסיפים

דרך הדפדפן: נכנסים לתיקייה הרצויה, `Add file` ← `Upload files`.
דרך git: מעתיקים לתיקייה, `git add`, `git commit`, `git push`.

בשני המקרים ה-workflow בונה מחדש את `index.json` לבד. אין צורך להריץ כלום.

## מה לא מוצג

`README.md`, `.gitkeep`, וכל קובץ ששמו מתחיל בנקודה — מסוננים על ידי
`tools/build_index.py`. קובץ README מסביר תיקייה למי שמדפדף כאן ב-GitHub; באפליקציה
הוא רק היה חוסם את התוכן האמיתי בכל תיקייה.

## מגבלת גודל

GitHub חוסם קובץ בודד מעל 100MB. קובץ מעל 50MB עובר עם אזהרה. לקבצים כבדים —
לצרף ל-Release במקום, ולא לשים כאן.
